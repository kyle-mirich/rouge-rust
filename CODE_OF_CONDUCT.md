# Code of conduct

Everyone participating in this project should be able to contribute without
harassment. Be respectful, discuss ideas on their merits, and give actionable
feedback. Welcome people with different backgrounds and levels of experience.

Harassment, discrimination, threats, personal attacks, sexualized attention, and
sharing someone else's private information without consent are unacceptable.
These expectations apply to issues, pull requests, reviews, and other project
spaces, including when representing the project elsewhere.

Maintainers may edit or remove harmful content, restrict participation, or ban
participants when necessary. Responses should be proportionate to the conduct
and take the safety and privacy of affected people into account.

To report a concern privately, use the contact options on
[the maintainer's GitHub profile](https://github.com/kyle-mirich). Avoid posting
sensitive details in a public issue. Maintainers will handle reports discreetly
and may request more information before taking action.
